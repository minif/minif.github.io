# Works and Projects I have made
Here is a list of projects I have worked on. Feel free to check them out. This page is mostly intended to be a showcase of my journey in programming.

# Coding Projects

### [Explora-ball](https://github.com/minif/Explora-Ball)
"An iPhone OS 2.0 game created 17 years late. This is an iPhone OS 2.0 game, made to run on the original iPhones and iPods that released during this time. Use the accelerometer to move balls into the goal to move onto the next level. This game features 75 levels, with different mechanics to explore."

This was a realization of a lifelong desire of mine to make an iOS app, as well as a video game! In the process I learned about OpenGL, Objective C, XCode, and other (older) technologies to make iOS apps. My goal was also to help inspire other people to make iOS apps, akin to the homebrew scene for other video game consoles. I hope to take this knowledge and create more iOS apps for old iOS devices in the future. 

![Explora-ball screenshot](/images/works/EXPB.PNG)

### [Ultimate Angler A+ Tracker](https://minif.github.io/ultimate-angler-a-plus-tracker/)
This is a simple Javascript-based web tool that tracks A+ fish catches in Ultimate Angler. Ultimate Angler (otherwise known as Streetpass Fishing) is one of the Streetpass Mii Plaza minigames that was avalible for purchase. I played this game throughout the first half of 2020, and needed a way to figure out what island to pick to optimally catch A+ fish. Using this tool, I was able to complete all A+ catches in that game.

### [iphoneos-2-app-fixer](https://github.com/minif/iphoneos2-app-fixer)
This is a simple script to modify iOS .ipa files to allow for sideloading on iPhone OS 2. For a while it was not well known why certain iOS apps were able to be sideloaded to iPhone OS 2, while others were not. I had looked into the differences between .ipa files and wrote a very simple app to apply the correct metadata. 

### [yt-comment-viewer](https://github.com/minif/yt-comment-viewer)
When Youtube removed the discussions tab, I had made a simple JS viewer to read those discussions. The file format I saved a limited test sample for, and the file format saved by archive-team may differ however so it may not have immediate use. 

### [JCView](https://github.com/minif/JCView)
This is a level viewer for JellyCar 3 Levels. I was originally going to expand it to also support level editing but I never did. 

### [easy-ipa-gui](https://github.com/minif/easy-ipa-gui)
This is a very rudamentry tkinter GUI to make usage of ipatool-py easier. It also featured additional features to view purchases on a users' Apple ID and to mass-download selected iOS apps. Unfortunately this tool no longer works as Apple has changed the underlying APIs, and I do not have the skill set to fix it.

### [Soap Mans World + Solar Magic](https://github.com/minif/solar-magic/releases/tag/v1.2-pv)
An old computer science final project I co-created. It was a basic 2D platformer inspired by Super Mario World rom hacking. 

### [PickANumber](/works-js-games/PickANumber/index.html)
An old game from when I was first learning JavaScript. Uses the concept of binary search to guess a number in a low number of tries.

### [TicTacToe](/works-js-games/TicTacToe/index.html)
My first ever JavaScript game. Its a 2 player version of Tic Tac Toe. I believe this was made around 2017.

# Minif's Place past versions
I have included a look back at all three iterations of "minif's place" with only minor modifications to avoid having broken links. I have only decided to include the homepage as the content of each site is not the purpose of these showcases. To return, use your web browser's back button. 

It is also important to note that these websites were titled "Minif's Place" back when I was indecisive of the capitalisation of my username. I have now decided to officially settle on "minif" (all lower case) and will name all future versions of my sites to follow as such. These sites will retain the capitalized versions of my username for historical purposes.

### [Minif's Place v1](/works-older-sites/1/)
This was my initial iteration of my website, generated using the long forgotten software iWeb. This was the birthplace of minif's place, and featured a blog, photo gallery, and a page to showcase my Scratch projects. This iteration was never publicly accessible on the internet. Unfortunately I do not have the original iWeb project, which is a bit of a shame. This era spanned from 2016-2017.

### [Minif's Place v2](/works-older-sites/2/)
After learning basic HTML and CSS, I wanted to replace my iWork website with one written entirely by me. Personally, I think this version is the "cleanest" version of my websites despite the simplistic styling, and while the other two versions look better this one has a colour choice I still really like. Initially the menu bar was made of HTML `<buttons>` but they were eventually replaced with the `<a>` tag. This era spanned from 2017-2020.

This was around the time when I made my website public on the internet. I used a tunneling service called ngrok to make my website available on the internet. At the time the ngrok free plan did not have a persistant domain name option so every time my server restarted I would get a new link. I lived with this limitation as it was free and not many people visited.

### [Minif's Place v3](/works-older-sites/3/)
This was the first time where I decided to style my website with a specific creative vision in mind. I took a bit of inspiration from mid to late 2000s hobby websites. The most notable aspect of my website was featuring a banner along the top with the title overtop a pixel art city landscape. My interpretation of minif's place has been "a big city with a lot of places but no people" (I will probably talk about this more in a blogpost) so my focus of the banner was on a simplistic city skyline. I also made a repeating tile texture to make a more interesting background for content than a solid colour.

In this iteration I shifted a bit away from making a personal website and making it more feature rich. I had changed my blog to be a "News" page with a focus on updates to the site itself. I also added a javascript based "Photo Viewer" rather than having all my photos on one page. I got a bit more serious with javascript based features to make things easier for me to add (without using a static website generator).

Around 2022, I decided to partially migrate over to github pages. Much of the main website was put on github pages, but I also had a script that obtained the temporary ngrok link to use with large files. That way I would have the best of both worlds. I ended it however when ngrok started to use your public IP as the domain name. This era spanned from 2020-2023.
