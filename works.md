# Works and Projects I have made
Here is a list of projects I have worked on. Feel free to check them out. This page is mostly intended to be a showcase of my journey in programming, and as such I included many rudamentry projects.

# Coding Projects

### [Explora-ball](https://github.com/minif/Explora-Ball)
An iPhone OS 2.0 game created 17 years late. This is an iPhone OS 2.0 game, made to run on the original iPhones and iPods that released during this time. Use the accelerometer to move balls into the goal to move onto the next level. This game features 75 levels, with different mechanics to explore.

This was a realization of a lifelong desire of mine to make an iOS app, as well as a video game! In the process I learned about OpenGL, Objective C, XCode, and other (older) technologies to make iOS apps. My goal was also to help inspire other people to make iOS apps, akin to the homebrew scene for other video game consoles. I hope to take this knowledge and create more iOS apps for old iOS devices in the future.

### [Ultimate Angler A+ Tracker](https://minif.github.io/ultimate-angler-a-plus-tracker/)
This is a simple Javascript-based web tool that tracks A+ fish catches in Ultimate Angler. Ultimate Angler (otherwise known as Streetpass Fishing) is one of the Streetpass Mii Plaza minigames that was avalible for purchase. I played this game throughout the first half of 2020, and needed a way to figure out what island to pick to optimally catch A+ fish. Using this tool, I was able to complete all A+ catches in that game.

### [iphoneos-2-app-fixer](https://github.com/minif/iphoneos2-app-fixer)
This is a simple script to modify iOS .ipa files to allow for sideloading on iPhone OS 2. For a while it was not well known why certain iOS apps were able to be sideloaded to iPhone OS 2, while others were not. I had looked into the differences between .ipa files and wrote a very simple app to apply the correct metadata. 

### [yt-comment-viewer](https://github.com/minif/yt-comment-viewer)
When Youtube removed the discussions tab, I had made a simple JS viewer to read those discussions. The file format I saved a limited test sample for, and the file format saved by archive-team may differ however so it may not have immediate use. 

### [JCView](https://github.com/minif/JCView)
This is a level viewer for JellyCar 3 Levels. I was originally going to expand it to also support level editing but I never did. 

### [easy-ipa-gui](https://github.com/minif/easy-ipa-gui)
This is a very rudamentry tkinter GUI to make usage of ipatool-py easier. It also featured additional features to view purchases on a users' Apple ID and to mass-download selected iOS apps. Unfortunately this tool no longer works as Apple has changed the underlying APIs, and I do not have the skill set to fix it.
