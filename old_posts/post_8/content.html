July 26 2021 - Transition to Github

Since 2016, Minif's place has been solely hosted off of my own hardware. This has allowed for greater control over my own site, rather than relying on a service that forefits my control over my site. However, running a site like this has resulted in some limitations. Most importantly, the method I use for obtaining an address is through NGROK, which does not allow a permenant link with a free account.

Because of this, I have decided to move Minif's Place to github, so that it remains permenantly online. I will continue to use the server for large files, such as for the photos library and merch store. This allows for the best of both worlds, in terms of remaining online as well as large file storage.

I will begin transitioning today and hope to finish it this summer.
