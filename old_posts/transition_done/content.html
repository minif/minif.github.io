May 21 2022 - Transition to Github: Complete

After way too many months of delaying, I have finally completed my migration to Github Pages!

So far, the biggest perk is the complete state of automation. My server auto-commits the current server link on reboot, and my API can parse that link and use it immediately. Other sites can even incorporate my script to obtain the link if needed. This means that, so long as my server has power and internet, Minif's Place should operate completely without me. The external server also means some files can appear "green" and be on my server, while others can be on Github.

Another large benefit I have is the usage of JSON to store information and metadata for content. Previously, I had used a crude method of using JS with arrays, and that was a pain to maintain. Now, I just need to add a couple of entries to a file and then the changes are done. This also means re-organisation can be done programatically much easier.

I have also completely purged the server and started it fresh. Yes, a lot of old files are no longer accessable, and a lot of the quirks (random files scattered about) are gone. This was mostly for privacy reasons. I will be adding back some things, like the /Old directory.

If you encounter any issues, pelease contact me via the email on the homepage.
