# Welcome to minif.github.io
Hi! Welcome to minif.github.io. This is a personal website that I have created to serve as a place for me to write about my interests and share things I have made. Please enjoy!

This website is hosted using Github Pages (in case you were not aware from the URL). It is written with the goal of taking advantage of [jekyll](https://jekyllrb.com), as it is build into Github Pages. Also, the styling of this website is temporary, so stay tuned for when I develop a replacement.

In the past, my personal websites were under the name "minif's place". The goal of that was to serve—as the name suggests—a place for me (minif) to share things. Therefore I stubbornly insist that minif's place must be self-hosted as much as possible. This, combined with my desire for the next iteration "v4" of minif's place to be written with a PHP backend, as well as general busyness, has lead me to make this website for the time being.
